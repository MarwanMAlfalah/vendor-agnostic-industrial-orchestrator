# Citation To Claim Matrix

Scope: maps major journal-manuscript claims to the current local evidence in `docs/source_materials/_Literature_Review_Marwan.xlsx`, `docs/source_materials/Thesis_Master_Marwan.pdf`, and the existing deterministic evaluation reports. This file does not add new experimental claims.

Citation strength scale:

- `core`: directly supports the claim and should be cited near the claim.
- `supporting`: useful context, but not sufficient alone.
- `weak`: only tangentially relevant or incomplete.
- `needs verification`: reference metadata, publication status, DOI, venue, or factual detail must be verified before submission.

## Citation Placement Guidance

Use the thesis for motivation and gap framing, not as a substitute for peer-reviewed or standards citations. Use the Excel references as candidate citations, but verify all bibliographic metadata before final IJTech submission.

Recommended citation clusters:

- Heterogeneity and interoperability: Thesis 1.1, Thesis 2.5, P4, P10, P20.
- LLM/MAS industrial reasoning: P1, P2, P5, P7, P10.
- Workflow/tool orchestration: P11, P12, P13, P14, P16.
- Governance and evaluation: P18, P19, Thesis 4.4.2, project evaluation reports.
- Bounded prototype claims: project threats-to-validity docs and thesis deployment-gap sections.
