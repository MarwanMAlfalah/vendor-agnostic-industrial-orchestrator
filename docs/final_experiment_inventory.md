## Reproducibility Notes

All runner output filenames are fixed. Policy metrics are deterministic. Local
timing values can vary slightly by machine and run.

## LangSmith Evidence Notes

For scaled evaluation screenshots, prioritize traces that show policy
compliance, approval continuation, invalid approval containment, and restart
recovery. Restart recovery screenshots should come from the existing
crash/restart demo because scaled evaluations use in-memory runs. LangSmith is
observability evidence, not industrial deployment evidence.
