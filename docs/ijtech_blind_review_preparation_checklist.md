# IJTech Blind Review Preparation Checklist

## Identity And Repository

- Remove author names and affiliations from the manuscript.
- Remove personal GitHub identity from manuscript text and figure screenshots.
- Avoid screenshots showing email addresses, usernames, organization names, or browser account details.
- Use an anonymized repository link if repository access is required during review.
- Remove or anonymize local filesystem paths that reveal identity.

## Figures

- Prepare a graphical abstract if required by the target venue.
- Export figures at 300 dpi or higher.
- Ensure all figure text is readable in grayscale.
- Avoid LangSmith screenshots that expose account identity.
- Caption LangSmith figures as observability evidence only.

## Tables

- Keep tables editable, not screenshots.
- Use consistent runtime names across all tables.
- Present original and aligned metrics together where relevant.
- Clearly mark deterministic synthetic scenario results.

## References

- Use Harvard reference style.
- Verify every citation manually before submission.
- Do not cite internal repository files as external scholarly sources.

## Claims And Limitations

- Do not claim certified safety.
- Do not claim production deployment.
- Do not claim live PLC integration.
- State that adapters are mock implementations.
- State that scenarios are deterministic and synthetic.
- State that Wilson intervals are scenario-distribution intervals, not stochastic LLM uncertainty.

## Final Checks

- Confirm manuscript title page is anonymized.
- Confirm acknowledgements are removed for blind review.
- Confirm supplementary material is anonymized.
- Confirm all CSV tables used for manuscript tables are included and editable.
